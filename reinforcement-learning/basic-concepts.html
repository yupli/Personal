第 1 课 · 基本概念 · V2（总结） ​

1. States, Actions & Transitions ​

（1）状态与状态空间 ​

状态与状态空间
  • State（状态）：智能体（agent）相对于环境所处的情形，记作 s。
  • State space（状态空间）：所有可能状态的集合，记作 S，因此 s∈S。若有 N 个状态，可写成 S={s1,…,sN}。

（2）动作与动作空间 ​

动作与动作空间
  • Action（动作）：智能体在当前状态下可以做出的一项选择，记作 a。
  • Action space of a state（该状态的动作空间）：状态 s 下所有可用动作的集合，记作 A(s)。智能体在状态 s 选择的动作满足 a∈A(s)。不同状态的可用动作可以不同。

（3）状态转移与转移概率 ​

状态转移与转移概率

State transition（状态转移）：智能体在状态 s 执行动作 a 后，环境产生下一状态 s′，记作 s→as′。下一状态也可能仍是 s。

State transition probability（状态转移概率）：给定当前状态 s 和动作 a，下一状态是 s′ 的概率。

p(s′∣s,a)=Pr(St+1=s′∣St=s,At=a),∑s′∈Sp(s′∣s,a)=1.
  • Deterministic transition（确定性转移）：给定 (s,a) 后，只有一个下一状态的概率为 1，其余为 0。
  • Stochastic transition（随机转移）：即使给定同一个 (s,a)，也可能出现多个不同的下一状态，概率分配在这些状态上。

环境同时给出下一状态 s′ 和即时奖励 r，可用联合分布（joint distribution）p(s′,r∣s,a) 描述。离散情形下，对奖励求和得到状态转移概率；对下一状态求和得到奖励概率：

p(s′∣s,a)=∑rp(s′,r∣s,a),p(r∣s,a)=∑s′p(s′,r∣s,a).

2. Policy ​

（1）策略怎样选动作 ​

Policy · 从状态到动作

Policy（策略）规定智能体在每个状态怎样选动作。π(a∣s) 表示在状态 s 选择动作 a 的概率：

π(a∣s)≥0,∑a∈A(s)π(a∣s)=1.
  • Deterministic policy（确定性策略）：为每个状态指定一个动作 a∗(s)，即 π(a∗(s)∣s)=1，其他动作的概率为 0。
  • Stochastic policy（随机策略）：可以把正概率分给多个可用动作，再按这个分布抽样。

策略决定选什么，环境决定选定后会到哪里。 固定当前状态 s，先选中指定动作 a、再到达 s′ 的联合概率是：

Prπ(At=a,St+1=s′∣St=s)=π(a∣s)p(s′∣s,a).

3. Rewards, Trajectories & Returns ​

（1）Reward、Trajectory 与 Return ​

从单步奖励到整条轨迹的回报

Reward（奖励）是执行动作后由环境给出的实数。正奖励鼓励这样的行为，负奖励用来惩罚这样的行为。Rt+1 是在 St 执行 At 后收到的那一笔即时奖励。

Trajectory（轨迹）是按时间排列的状态、动作和奖励。箭头上方是执行的动作，下方是获得的奖励：

St→Rt+1AtSt+1→Rt+2At+1St+2→ ⋯ ST.

Return（回报）累加一段轨迹上的奖励。对在时刻 T 结束的轨迹，从时刻 t 起的未折扣回报是 Rt+1+Rt+2+⋯+RT。

（2）Discounted return 与折扣因子 ​

Discounted return · 折扣回报

引入 discount factor（折扣因子） γ∈[0,1)。第一笔奖励的权重为 1，之后每晚一步就多乘一个 γ：

Gt=Rt+1+γRt+2+γ2Rt+3+⋯=∑k=0∞γkRt+k+1.
  • 让无限和保持有限。 如果每步奖励有界（|Rt+k+1|≤Rmax），折扣回报的绝对值至多为 Rmax∑k=0∞γk=Rmax/(1−γ)。例如，若前 m 步奖励为零、之后每步都是常数 r，则 Gt=rγm(1+γ+γ2+⋯)=rγm/(1−γ)。
  • 调节近期与远期奖励的权重。 γ=0 时只计第一笔奖励；γ 接近 0 时远期权重衰减很快，接近 1 时衰减更慢，远期奖励因此更有分量。

4. Episodic & Continuing Tasks ​

（1）Episode 与两种任务 ​

Episode · 从开始到终止
  • Episode（回合，也称 trial）：智能体按策略与环境交互，从初始状态开始，到达 terminal state（终止状态）时停止；这段完整的有限轨迹就是一个回合。
  • Episodic task（回合型任务）：交互由一个个有终点的回合组成。若在时刻 T 终止，进入终止状态时获得的 RT 是回合最后一笔奖励；从 T 开始没有后续奖励，所以 GT=0。
  • Continuing task（持续型任务）：没有规定的终止状态，智能体可以一直与环境交互。

（2）怎样用持续形式表示回合任务 ​

两种处理目标状态的方式
  1. 设为 absorbing state（吸收状态）。 到达后只转移到自身，之后奖励恒为 0；进入时获得的奖励照常计入。这样可以把有限轨迹补成无限轨迹，同时保留原来的回报。
  2. 当作普通状态。 到达目标后仍按策略行动，可以离开；每次进入目标时都可按规则获得奖励（课件设为 +1）。课程采用这种设定，因此目标状态也能用与其他状态相同的方式处理。由于首次到达后仍可能继续得分，这是一个重新定义的持续任务，回报可能与原回合任务不同。

5. Markov Decision Process (MDP) ​

（1）MDP 的组成与 Markov property ​

Markov Decision Process · 基本要素
  • 集合（sets）：S 是全部状态的集合；A(s) 是状态 s 的可用动作集合；R(s,a) 是在 s 执行 a 后可能获得的奖励值的集合。
  • 环境的概率分布：p(s′∣s,a) 是到达 s′ 的状态转移概率，p(r∣s,a) 是获得 r 的奖励概率。联合分布 p(s′,r∣s,a) 同时描述两种结果。
  • 策略（policy）：π(a∣s) 描述智能体在 s 选择 a 的概率。同一个 MDP 可以用来比较不同策略；折扣因子 γ 决定怎样给未来奖励加权。

Markov property（马尔可夫性质）也叫无记忆性：给定当前状态 st 和本步动作 at 后，再知道更早的交互历史，也不会改变下一状态和奖励的条件分布。令 ht=(s0,a0,r1,…,at−1,rt,st) 表示截至当前状态的历史，则

p(st+1,rt+1∣ht,at)=p(st+1,rt+1∣st,at),p(st+1∣ht,at)=p(st+1∣st,at),p(rt+1∣ht,at)=p(rt+1∣st,at).

第一行是联合分布的条件；后两行分别对应只看下一状态、只看即时奖励。

（2）固定策略后得到 Markov process ​

从 MDP 到 Markov process

固定一个只依赖当前状态的策略 π 后，在 s 怎样选动作已经确定为分布 π(⋅∣s)。将「先选 a、再到达 s′」的概率对所有可用动作求和，就得到只依赖当前状态的一步转移概率：

pπ(s′∣s)=∑a∈A(s)π(a∣s)p(s′∣s,a).

因此，在策略 π 下，只看状态序列 S0,S1,…，它就是一个 Markov process（马尔可夫过程）。第 2 课会用这个转移概率推导 Expected Future Return。
