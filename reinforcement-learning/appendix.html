第 2 课 · 策略评估的收敛证明 ​

返回第二课 · 矩阵形式与策略评估

Proof · 为什么迭代会收敛？

固定策略 π，设有限状态转移矩阵 Pπ 的每一行都是概率分布，折扣因子 0≤γ<1。真实价值 vπ 满足贝尔曼方程，迭代从任意 v0 出发：

vπ=rπ+γPπvπ,vk+1=rπ+γPπvk.

（1）写出误差的递推式。 令 δk=vk−vπ。代入 vk+1=δk+1+vπ 和 vk=δk+vπ：

δk+1+vπ=rπ+γPπ(δk+vπ),δk+1=γPπδk+(rπ+γPπvπ−vπ)=γPπδk.

括号里的三项由贝尔曼方程正好抵消。反复代回推到初值：

δk=γPπδk−1=⋯=γkPπkδ0(k≥1).

（2）说明为什么矩阵不会放大误差。 令 1 为全 1 列向量。因为 Pπ1=1，所以 Pπk1=1；矩阵的元素仍非负，故每个元素都在 [0,1] 内。Pπkδ0 的每个分量都是初始误差各分量的加权平均，绝对值不超过最大的初始绝对误差：

∥δk∥∞≤γk∥δ0∥∞→k→∞0.

因此 vk→vπ。同样的性质也保证 I−γPπ 可逆：若 (I−γPπ)x=0，则 ∥x∥∞≤γ∥x∥∞，在 γ<1 时只可能有 x=0。

用相邻两轮的差估计误差。 令 Δ=∥vk+1−vk∥∞。展开迭代式可知，之后的第 j 次变化不超过 γjΔ（从 j=1 开始）。把之后的各次变化加总，即得 ∥vk+1−vπ∥∞≤γΔ/(1−γ)。

第 6 课 · Robbins–Monro Convergence Conditions ​

返回第六课 · Robbins–Monro Theorem

（1）What the Three Conditions Control ​

Slope, Step Sizes and Noise
  • Slope bounds。g′(w)≥c1>0 让 g 严格递增，并在 w→±∞ 时分别走向 ±∞，所以有唯一的 root。上界 g′(w)≤c2 控制给定距离下 g(w) 的大小。
  • Step sizes。平方可和保证 ak→0，而 ∑kak=∞ 让剩余的总步长一直足够大。
  • Noise。给定历史后，noise 的均值为零，表示观测没有系统性漂移。常见例子是与初值独立、均值为零、方差有限的 i.i.d. noise，分布可以是非 Gaussian 的。

（2）Why Square Summability Matters ​

Square Summability · 压低后期 Noise

在 root 附近，g(wk) 变小，noise 仍会扰动单步更新：

wk+1−wk=−akg(wk)−akηk.

如果 wk 最终收敛，相邻两步的差必然趋于零。在定理的 noise 条件下，每个加权 noise 的条件二阶矩至多为 Mak2，所以平方可和把这些扰动的二阶矩总量控制在有限范围内。

（3）Why the Sum of Step Sizes Diverges ​

Infinite Total Step Size · 留足后续修正空间

将前 n 步累加，得到总位移：

wn+1−w1=−∑k=1nakg~(wk,ηk).

式子右侧的负号来自 update rule。若观测的绝对值至多为 B，而 ∑kak 有限，则总位移最多为 B∑kak。当初值离 root 比这个上界还远时，迭代走不到 root。这说明 step size 不能缩得太快。

（4）A Step-Size Sequence That Works ​

Example · aₖ = 1/k

对于 ak=1/k，harmonic series 的部分和随 ln⁡n 增长：

limn→∞(∑k=1n1k−ln⁡n)=κ≈0.577.

这里 κ 是 Euler–Mascheroni constant。因此 ∑kak=∞。平方和则是 Basel problem 给出的有限值：

∑k=1∞ak2=∑k=1∞1k2=π26.

（5）Dvoretzky’s Convergence Theorem ​

Theorem · Dvoretzky’s Convergence Theorem

考虑以下标量随机递推。ek 表示要收敛到零的量，对应图中的 wk：

ek+1=(1−αk)ek+βkξk.

Hk 包含当前的 ek 和此前的观测、迭代与系数。允许 αk,βk≥0 随历史变化，两者在收到本轮 noise ξk 前已经确定。

  1. Coefficients。几乎必然有 ∑kαk=∞。两组平方和 ∑kαk2、∑kβk2 几乎必然有限，并有与样本路径无关的上界。可用与样本路径无关的发散下界验证第一项。
  2. Noise。几乎必然有 E[ξk∣Hk]=0 和 E[ξk2∣Hk]≤C<∞，其中 C 与 k 无关。

于是 ek→0 almost surely。课程教材 Theorem 6.2

Applying the Theorem to Robbins–Monro ​

Proof Sketch · 把 Root Estimate 写成 Error Recursion

令 ek=wk−w∗。由 mean value theorem，可写 g(wk)−g(w∗)=bkek，其中 c1≤bk≤c2。当 ek≠0 时，bk 取两点间的 secant slope，因此收到本轮观测前就已确定。ek=0 时可取 bk=c1。

代入 RM 的 update rule，得到

ek+1=(1−akbk)ek+ak(−ηk).
  • 取 αk=akbk、βk=ak 和 ξk=−ηk。
  • αk≥c1ak 保证总和发散，αk≤c2ak 保证平方和有限。βk 的平方和也有限。
  • 换号后的 noise 保持条件零均值和二阶矩上界。

于是 ek→0 almost surely，也就是 wk→w∗ almost surely。

Other Applications ​

  • Mean estimation。令 ek=wk−μ，其中 μ=E[X]。第一节的 update rule 对应 αk=βk=1/k、ξk=xk−μ。若按课件取 w1=x1，则从 k=2 起，对方差有限的 i.i.d. samples 应用定理，就能得到 almost sure convergence。
  • TD learning and Q-learning。这一定理的扩展可用于分析同时更新多个 states 或 state–action pairs 的收敛。课程教材 §6.3.2–6.3.4

第 6 课 · SGD as Robbins–Monro ​

From GD to SGD · True Gradient and Sample Gradient

在可以交换微分和期望的条件下，GD 使用 true gradient，SGD 使用单个 sample 给出的 gradient：

GD:wk+1=wk−αkEX[∇wf(wk,X)],SGD:wk+1=wk−αk∇wf(wk,xk).

二者的差异来自本轮 sample 的 gradient noise。

From Optimization to Root Finding

对可微的无约束目标 J(w)=EX[f(w,X)]，minimizer 满足 stationarity condition。令

g(w)=∇wJ(w)=EX[∇wf(w,X)].

求 stationary point 就写成 root-finding problem g(w)=0。当 J 是 strongly convex 时，这个 root 是唯一的 minimizer。

Robbins–Monro Update · Identify the Noise

在 wk 处，把 sample gradient 写成 noisy observation：

ηk=∇wf(wk,xk)−g(wk),g~(wk,ηk)=g(wk)+ηk=∇wf(wk,xk).

如果 xk 独立于抽样前的历史 Hk 且服从 X 的分布，那么 E[ηk∣Hk]=0。令 RM 的 step size ak=αk，代入其 update rule：

wk+1=wk−akg~(wk,ηk)=wk−αk∇wf(wk,xk).

这就是 SGD。这个等式也适用于 vector parameters。标量版本的 almost sure convergence 还需要正文定理中的 curvature、step size 和 noise 条件。

第 8 课 · Linear TD and the Projected Bellman Equation ​

返回第八课 · Linear Features

令 D=diag(dπ)，Φ 的每行是一个状态的 feature 向量。线性近似可表示的价值向量为 v^=Φw。用 Tπv=rπ+γPπv 表示 Bellman operator，ΠD 表示按 D 加权的正交投影。

  • True Value Error 比较 Φw 和真实价值 vπ。
  • Bellman Error 比较 Φw 和 Tπ(Φw)。
  • Projected Bellman Error 比较 Φw 和 ΠDTπ(Φw)。

在有限、遍历的 on-policy Markov chain、折扣 γ<1、满列秩 feature 和适当递减步长等标准条件下，TD(0) 的线性近似收敛到满足下式的参数：

Φw=ΠDTπ(Φw).

在平稳分布下对 linear TD 的更新取期望。平均更新为零时，Bellman residual 与每个 feature 在 D 内积下正交：

Φ⊤D[Tπ(Φw)−Φw]=0.

这正是 projected Bellman equation 的条件。它从当前近似做一次 Bellman backup 再投影。直接拟合真实价值 vπ 对应的则是 ΠDvπ。
