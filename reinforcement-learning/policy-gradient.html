第 9 课 · 策略梯度方法 ​

1. Basic Idea of Policy Gradient ​

1.1 从 Tabular Policy 到 Parameterized Policy ​

Tabular Policy · 每个状态动作对有一个概率

在 tabular representation 中，用状态 s 和动作 a 索引一个表项 π(a∣s)。每个状态的一行存放所有可用动作的概率。

Parameterized Policy · 多个状态共享参数

把策略写成 parameterized function π(a∣s,θ)，其中 θ∈Rm 是 parameter vector。例如，在离散动作空间中，神经网络以状态 s 为输入，以 θ 为网络参数，输出这一状态下各个动作的概率。

  • Storage。大状态空间下，可以用同一组参数表示多个状态的策略，减少逐状态存储。
  • Generalization。用某个状态的经验更新共享参数，可能同时改变其他状态的动作概率。

1.2 两种表示如何定义、读取和更新策略？ ​

Optimal Policy · 怎样定义最优？
  • Tabular policy。前面课程中的最优策略要同时达到每个状态的最优价值 v∗(s)。
  • Parameterized policy。共享参数可能让不同状态的价值此消彼长，因此选一个 scalar metric J(θ)，在给定的参数化策略族中寻找使它最大的策略。
Action Probability · 怎样读取动作概率？
  • Tabular policy。直接查表得到 π(a∣s)。
  • Parameterized policy。给定函数结构和当前参数 θ，计算 π(a∣s,θ)。
Policy Update · 怎样更新策略？
  • Tabular policy。直接修改某个状态下各动作的概率表项。
  • Parameterized policy。更新 θ，再由函数给出新的动作概率。

1.3 Policy Gradient · 先定义目标，再沿梯度更新 ​

Basic Idea · Objective Function 与 Gradient Ascent
  1. Define the objective。选定标量目标 J(θ)，衡量策略 π(⋅∣⋅,θ) 的表现。
  2. Optimize the parameters。用 gradient ascent 沿 J 增大的方向更新 θ。
θt+1=θt+α∇θJ(θt).

α>0 是 step size，∇θJ(θt) 就是 policy gradient。

2. Metrics to Define Optimal Policies ​

2.1 Average Value ​

Metric 1 · Average State Value

课件介绍两种衡量策略表现的指标。第一种是 average state value，简称 average value。它把各状态在策略 π 下的价值加权成一个标量。

v¯π=∑s∈Sd(s)vπ(s)=ES∼d[vπ(S)].

每个状态的权重满足 d(s)≥0，且 ∑sd(s)=1，因此可以把 d 看作状态分布。

Vector-product Form

按同一状态顺序，把权重和状态价值分别排成列向量 d 与 vπ，两者都属于 R|S|。Average value 就是它们的内积。

vπ=[vπ(s1),…,vπ(s|S|)]⊤,d=[d(s1),…,d(s|S|)]⊤,v¯π=∑s∈Sd(s)vπ(s)=d⊤vπ.
Case 1 · 与策略无关的固定分布

将固定分布记为 d0，对应指标为 v¯π0=d0⊤vπ。策略参数变化时，d0 保持不变，求梯度时只需对状态价值求导。

  • Uniform distribution。取 d0(s)=1/|S|，给所有状态相同的权重。
  • Fixed initial state。如果每个 episode 都从 s0 开始，取 d0(s0)=1，且对 s≠s0 取 d0(s)=0。此时 v¯π0=vπ(s0)，衡量的是从 s0 出发的期望折扣回报。
Case 2 · 随策略变化的 Stationary Distribution

也可以取 d=dπ，即策略 π 诱导的 stationary distribution。令 Pπ 为该策略下的状态转移概率矩阵，则

dπ⊤Pπ=dπ⊤,v¯π=dπ⊤vπ.

在遍历条件下，长期访问频率越高的状态权重越大，较少访问的状态权重较小。策略变化时，dπ 也可能随之变化。第八课 · Stationary Distribution

2.2 Average Reward ​

Metric 2 · Average One-step Reward

Average reward 用平稳分布 dπ 对各状态的期望单步奖励加权。

r¯π=∑s∈Sdπ(s)rπ(s)=ES∼dπ[rπ(S)].

其中 rπ(s) 先按策略对动作取平均，r(s,a) 是给定状态和动作的期望即时奖励。

rπ(s)=∑a∈A(s)π(a∣s)r(s,a),r(s,a)=E[R∣s,a]=∑rrp(r∣s,a).
Equivalent Definition · 长期每步奖励

从 St=s0 开始按 π 行动，得到奖励序列 (Rt+1,Rt+2,…)。前 n 步的每步期望奖励等于奖励总和的期望除以 n。

1nEπ[Rt+1+⋯+Rt+n∣St=s0]=1n∑k=1n∑sPrπ(St+k−1=s∣St=s0)rπ(s).

若策略诱导的有限 Markov chain 遍历且奖励期望有限，式中的状态分布趋于 dπ。每步期望奖励及其时间平均都趋于 ∑sdπ(s)rπ(s)，因此

limn→∞1nEπ[∑k=1nRt+k∣St=s0]=limn→∞1nEπ[∑k=1nRt+k]=∑sdπ(s)rπ(s)=r¯π.

任意起点 s0 都给出同一个极限，因此也可对任意起始分布取期望。按平稳分布加权和沿轨迹取长期平均，是 r¯π 的两个等价定义。

2.3 Remarks on the Metrics ​

Remarks 1–2 · 参数与折扣
  • Parameter dependence。两种指标都随策略 πθ 变化，因此都可以选作要最大化的 J(θ)。
  • Discounted and undiscounted settings。Average value 来自折扣回报，通常取 0≤γ<1。在持续任务中，若采用 γ=1，无限奖励总和可能发散，可以用每步长期平均的 r¯π 定义目标。
Remark 3 · 平稳条件下的关系

Average reward 在定义里只出现单步奖励，但 dπ 已包含策略长期访问各状态的频率。若 Average Value 也用 d=dπ 加权，并且 0≤γ<1，则

r¯π=(1−γ)v¯π.

从 S0∼dπ 出发，之后每一步的状态分布都是 dπ，所以每步期望奖励都等于 r¯π。把它代入折扣回报并对几何级数求和，即得 v¯π=r¯π/(1−γ)。固定 γ 时，这两个指标对策略的排序相同。用一般的固定起点分布 d0 加权时，这一比例关系一般不成立。

2.4 Exercise · Expected Discounted Return ​

Exercise · 期望折扣回报对应哪个指标？

令 G0=∑t=0∞γtRt+1，目标为 J(θ)=E[G0]。从 S0∼d 开始生成轨迹。

S0,A0,R1,S1,A1,R2,S2,…

每步先按策略抽取 At∼πθ(⋅∣St)，再由环境的联合分布 p(r,s′∣St,At) 生成 (Rt+1,St+1)。期望同时涵盖起始状态、动作和环境转移的随机性。

对起始状态应用 law of total expectation。

J(θ)=∑s∈Sd(s)Eπθ[G0∣S0=s]=∑s∈Sd(s)vπθ(s)=v¯πθ.

所以它就是以起始分布 d 加权的 Average Value。

3. Gradients of the Metrics ​

3.1 Policy Gradient for Each Metric ​

Common Form · 状态加权的策略梯度

选定目标 J(θ) 后，先求 ∇θJ(θ)，再用梯度上升更新策略参数。上一节的三个目标 r¯π、v¯π 和 v¯π0 可以用同一种加权求和形式来表达梯度或其近似。

gπ(s;q)=∑a∈A(s)∇θπ(a∣s,θ)q(s,a),∑s∈Sη(s)gπ(s;q)=∑s∈Sη(s)∑a∈A(s)∇θπ(a∣s,θ)q(s,a).

η(s) 是状态权重。求导时要同时看目标（固定起点的 v¯π0、平稳加权的 v¯π 或 r¯π）及回报设定（折扣或不折扣）。下面分别写出精确梯度和课件采用的近似。由归一化带来的常数比例将在 3.2 节中保留。

Average Reward and Stationary Average Value

对长期平均奖励 r¯π，状态权重取平稳分布 dπ。在有限遍历情形下，用折扣动作价值 qπγ 可以得到课件中的近似。若采用平均奖励设定下的 differential action value qπdiff，以 Rt+1−r¯π 为中心化奖励来衡量后续回报，则策略梯度定理给出精确梯度。Sutton 等 · Policy Gradient Theorem

∇θr¯π≈∑sdπ(s)∑a∇θπ(a∣s,θ)qπγ(s,a)(γ→1−),∇θr¯π=∑sdπ(s)gπ(s;qπdiff).

若 v¯π 也以 dπ 加权，由上一节的 r¯π=(1−γ)v¯π，在固定 0≤γ<1 时可直接得到

∇θv¯π=11−γ∇θr¯π.
Fixed Start Distribution · 折扣状态访问权重

对 v¯π0，轨迹从固定分布 d0 出发。令 ρπ(s) 为从 d0 出发后访问状态 s 的 discounted occupancy，第 t 步的访问概率按 γt 加权。

ρπ(s)=∑t=0∞γtPrS0∼d0,π(St=s),∇θv¯π0=∑sρπ(s)∑a∇θπ(a∣s,θ)qπγ(s,a).

在持续任务中，∑sρπ(s)=1/(1−γ)。因此 (1−γ)ρπ 是可用于采样的概率分布，用它写成期望时需保留外部因子 1/(1−γ) 才得到原梯度。

3.2 Log-policy Form ​

A Compact Form of the Gradient

先令 Z=∑sη(s)>0，将状态权重归一化为 η~(s)=η(s)/Z。取 S∼η~、A∼π(⋅∣S,θ)，前面的加权求和可写成

∑sη(s)gπ(s;q)=ZE[∇θln⁡π(A∣S,θ)q(S,A)].
Sample-based Gradient · 用样本估计梯度

按 S∼η~、A∼π(⋅∣S,θ) 抽到一个样本 (s,a) 后，可用

Z∇θln⁡π(a∣s,θ)q(s,a)

估计上面的加权和。若该加权和等于目标的精确梯度，且采用对应的真实动作价值，这就是一个无偏梯度估计。多个样本可以取平均。状态从哪个分布采样，决定了这组样本估计的是哪种加权和。

How to Prove It? · Log-derivative Trick

对正概率动作，由链式法则有

∇θln⁡π(a∣s,θ)=∇θπ(a∣s,θ)π(a∣s,θ).

因此 ∇θπ=π∇θln⁡π。出现的 π(a∣s,θ) 恰好是动作的条件概率。用上面定义的 Z 和 η~，先把状态求和写成 S∼η~ 的期望，再把动作求和写成 A∼π(⋅∣S,θ) 的条件期望。

∑sη(s)gπ(s;q)=∑sη(s)∑aπ(a∣s,θ)∇θln⁡π(a∣s,θ)q(s,a)=ZES∼η~[∑aπ(a∣S,θ)∇θln⁡π(a∣S,θ)q(S,a)]=ZES∼η~[EA∼π(⋅∣S,θ)[∇θln⁡π(A∣S,θ)q(S,A)]]=ZE[∇θln⁡π(A∣S,θ)q(S,A)].

若 η 本身是概率分布，如 dπ，则 Z=1。

3.3 Softmax Policy ​

Softmax · 从动作分数到概率

计算 ln⁡π(a∣s,θ) 需要正概率。对有限实数向量 x=[x1,…,xn]⊤，softmax 给出的 zi 均为正，且 ∑izi=1。

zi=exi∑j=1nexj.

把状态 s 输入参数为 θ 的神经网络，令 h(s,a,θ) 为动作 a 的 logit。对可用动作的分数做 softmax，即得到策略

π(a∣s,θ)=eh(s,a,θ)∑a′∈A(s)eh(s,a′,θ).
Neural Network Policy · 输出层与探索

当所有状态共用动作集合 A 时，网络有 |A| 个动作输出。输出层使用 softmax，将每个动作的 logit 转成对应的 π(a∣s,θ)。有两个或更多可用动作时，每个动作的概率都在 (0,1) 内，因此可按这个随机策略在访问到的状态探索各个动作。也有直接对确定性策略求梯度的 Deterministic Policy Gradient（DPG） 方法。

4. Gradient-ascent Algorithm ​

4.1 From Expected to Stochastic Updates ​

Gradient Ascent · 从期望到样本

令 πt=π(⋅∣⋅,θt)。在上一节的梯度表达式成立时，令 Z 为状态权重总和，η~ 为归一化后的状态分布。用正的学习率 α 沿梯度方向更新参数。

θt+1=θt+α∇θJ(θt)=θt+αZE[∇θln⁡π(A∣S,θt)qπt(S,A)].

从对应的分布采到一个 (st,at) 后，先用含真实动作价值的单样本代替期望。以下沿用课件记法，将固定的正比例因子 Z 并入 α。

θt+1=θt+α∇θln⁡π(at∣st,θt)qπt(st,at).

真实的 qπt 通常未知。再以估计值 qt(st,at) 代入，得到实际使用的随机更新。

θt+1=θt+α∇θln⁡π(at∣st,θt)qt(st,at).

本课的 REINFORCE 用 Monte Carlo 回报估计动作价值。下一课再讨论 TD 估计。

4.2 On-policy Sampling ​

Remark 1 · How to Do Sampling?
  • 状态 S。对以 dπ 加权的目标，在遍历条件下，按当前策略运行得到的长期状态频率可近似 dπ。对固定起点的折扣目标，从 d0 出发产生轨迹，并按上一节的折扣访问权重计入各时间步。
  • 动作 A。在采到的状态 st，按当前策略抽取 at∼π(⋅∣st,θt)。用于更新的轨迹来自待优化的策略，因此这里采用 on-policy 采样。

4.3 Interpreting the Update ​

Remark 2 · How Does the Sampled Action Probability Change?

用上一节的 log-derivative 恒等式，可把随机更新改写为动作概率梯度乘上有符号的系数 βt。

βt=qt(st,at)π(at∣st,θt),θt+1=θt+αβt∇θπ(at∣st,θt).

记 pt(θ)=π(at∣st,θ)。对抽到的这个状态和动作做一阶 Taylor 展开。

pt(θt+1)−pt(θt)≈∇θpt(θt)⊤(θt+1−θt)=αβt∇θpt(θt)⊤∇θpt(θt)=αβt‖∇θpt(θt)‖2.

当步长足够小且 ∇θpt(θt)≠0 时，有

  • βt>0 沿动作概率的梯度前进，π(at∣st,θt+1)>π(at∣st,θt)。
  • βt<0 沿反方向前进，π(at∣st,θt+1)<π(at∣st,θt)。
  • βt=0 时，本次更新量为零。
Exploration and Exploitation · 系数 $\beta_t$ 的两部分
  • 分子 qt(st,at)。在动作概率和概率梯度给定时，价值估计越高，一阶概率增量越大。
  • 分母 π(at∣st,θt)。在价值估计和概率梯度给定时，概率较低的动作一旦被采到，系数的绝对值更大。对动作取期望时，分母与采样概率抵消，恢复动作求和中的 ∇θπ(a∣s,θt)。实际更新的幅度还取决于概率梯度，探索来自按随机策略采样。

4.4 REINFORCE Algorithm ​

Monte Carlo Policy Gradient

REINFORCE 是早期的策略梯度算法之一。它先用同一策略生成一个完整回合，再对每个 (st,at) 以从该步到终止的实际折扣回报 return-to-go 作为动作价值估计。

Gt=∑j=t+1Tγj−t−1rj,qt(st,at)=Gt.

在生成该回合的策略下，Gt 的条件期望就是 qπγ(st,at)。得到完整回报后，再用它给 log-policy 梯度加权。

课件中的 θk 是第 k 轮生成回合时的参数，内层 θt 从这组参数开始更新。末尾的 θk=θT 表示把更新完的参数带入下一轮，用外层下标可写成 θk+1←θT。

若要用整条轨迹构造固定起点折扣目标 v¯π0 的无偏梯度估计，可在采样回合的参数处计算所有 log-policy 梯度，将每步的 Gt 乘上 γt 后求和，再统一更新。γt 对应状态的折扣访问权重，Gt 内的折扣则从该步开始计算。Sutton & Barto · §13.3 REINFORCE
