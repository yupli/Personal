1. TD(0) · State-value Prediction ​

固定只依赖当前状态的策略 π。回报分解与马尔可夫性质给出

vπ(s)=Eπ[Rt+1+γGt+1∣St=s]=Eπ[Rt+1+γvπ(St+1)∣St=s].

给定真实 vπ，一次转移给出右端的样本。实际用当前 Vt 代替未知 vπ，形成 bootstrapped target。只更新访问到的状态：

Yt=Rt+1+γVt(St+1),δt=Yt−Vt(St),Vt+1(St)=Vt(St)+αt(St)δt.

课件把 TD error 定义为旧估计减目标，所以用减法更新。这里取相反号，结果相同。固定本轮 Yt 时，新估计与它的差乘上 1−αt。到达真正终止状态时令后续项为零。

从 Robbins–Monro 的角度，根方程是 V−TπV=0。把当前价值表视为给定时，样本残差 Vt(s)−Yt 的条件期望是 Vt(s)−[TπVt](s)。一次转移给出了当前方程残差的随机观测。自举目标的条件期望在固定点处等于真实状态价值。

表格型、有限、折扣且固定策略时，在各状态充分访问和满足标准噪声条件下，常用局部步长条件为 ∑tαt(s)=∞、∑tαt(s)2<∞。未访问该状态时记 αt(s)=0。这给出几乎必然收敛。常数步长适合持续更新，但不能由该定理推出样本路径收敛。

TD vs. Monte Carlo ​

AspectTDMonte Carlo
Update timing收到转移即可更新等到能计算完整回报
Target真奖励加当前估值实际轨迹回报
Bootstrapping有。目标依赖当前价值无。目标与初始化无关

2. Sarsa · Action-value Learning ​

观测五元组 (St,At,Rt+1,St+1,At+1)。固定策略时，下一动作按同一策略抽取：

Yt=Rt+1+γQt(St+1,At+1),Qt+1(St,At)=Qt(St,At)+αt[Yt−Qt(St,At)].

其他表项本轮不变。期望目标来自 qπ 的贝尔曼方程。固定策略评价的收敛要求逐状态动作对的覆盖与适当步长。用于 control 时，按同一 ε-greedy 策略采样和评价，并更新它，属于 on-policy 的广义策略迭代。固定正探索率评价的是含探索的策略。

3. Expected Sarsa & n-step Sarsa ​

Expected Sarsa 对下一动作求条件期望，环境仍用样本：

Yt=Rt+1+γ∑aπt(a∣St+1)Qt(St+1,a).

对给定的下一状态，这一步消除抽取单个动作带来的方差，代价是求和所需的动作值与概率。

n-step Sarsa 用前 n 步真实奖励，再用价值估计补后缀：

Gt(n)=∑j=0n−1γjRt+j+1+γnQ(St+n,At+n).

从 t 开始的更新必须等到第 n 步信息就绪，或等回合提前结束。提前结束时只累计到末笔奖励，去掉自举项。n=1 恢复 Sarsa，覆盖整个回合则得到 MC target。增加 n 通常减少对当前估计的依赖，同时纳入更多采样随机性。

4. Q-learning · Learning Optimal Action Values ​

用下一状态的最大动作值替换 Sarsa 的下一动作样本：

Yt=Rt+1+γmaxbQt(St+1,b),q∗(s,a)=E[Rt+1+γmaxbq∗(St+1,b)∣s,a].

第一行是一次样本更新的目标，第二行是要解的 Bellman optimality equation。课件第 58 页汇总表的 Q-learning 一栏漏写了折扣因子，按第 43 页及更新式补上 γ。

PolicyRole
Behavior policy生成经历，可保留探索概率
Target policy决定更新的学习目标。Q-learning 用当前 Q 的贪心动作

Sarsa 使用行为策略抽出的 At+1 评价同一策略。Q-learning 的最大值与实际执行的下一动作无关，属于 off-policy 更新。课件称第 50 页为 on-policy version，指边采样边更新用于生成经验的策略。该实现里的 Q 更新目标仍取最大值。第 51 页则直接使用独立行为策略已有的数据。无论使用哪种数据来源，仍需充分访问相关状态动作对。

课件的探索实验在比较数据覆盖。均匀探索生成的轨迹能覆盖更多状态动作对。若行为策略长期偏向少数动作，延长轨迹也可能只增加已常见的访问，稀少表项仍难学好。图中的纵轴比较训练中提取的贪心策略价值与已知最优价值的差距。

所有动作值更新都可写成 Q←Q+α(Y−Q)，区别集中在目标 Y。

n-step SarsaGt(n)给定策略的多步 BE
