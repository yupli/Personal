1. 时序差分（Temporal-Difference，TD）· 状态价值预测 ​

（1）算法描述 ​

TD 状态价值学习 · 算法描述

算法所需的经验

  • 按给定策略 π 生成轨迹 (s0,r1,s1,…,st,rt+1,st+1,…)，也可写作经验三元组 {(st,rt+1,st+1)}t。

TD 更新公式

{vt+1(st)=vt(st)−αt(st)[vt(st)−[rt+1+γvt(st+1)]],(1)vt+1(s)=vt(s),∀s≠st,(2)

其中 t=0,1,2,…。vt(st) 是对 vπ(st) 的当前估计，αt(st) 是状态 st 在第 t 步的学习率。

  • 第 t 步只更新当前访问的状态 st，其他状态按式（2）处理。
  • 下文可省略式（2）。

（2）TD target 与 TD error ​

给更新公式的各项加上标注。

vt+1(st)⏟新估计=vt(st)⏟当前估计−αt(st)[vt(st)−[rt+1+γvt(st+1)⏟TD target v¯t]⏞TD error δt].(3)

TD target（目标值）

v¯t=˙rt+1+γvt(st+1)

TD error（时序差分误差）

δt=˙vt(st)−[rt+1+γvt(st+1)]=vt(st)−v¯t

新估计等于当前估计减去学习率乘以 TD error。

（3）为什么称为 TD target ​

每次更新都会把当前状态的估计推向本轮目标。

更新式两边减去 v¯t，再提取公因子。

vt+1(st)=vt(st)−αt(st)[vt(st)−v¯t]vt+1(st)−v¯t=vt(st)−v¯t−αt(st)[vt(st)−v¯t]=[1−αt(st)][vt(st)−v¯t]|vt+1(st)−v¯t|=|1−αt(st)||vt(st)−v¯t|.

当学习率满足 0<αt(st)<1 时，

0<1−αt(st)<1.

于是，新估计与本轮目标的距离缩小。

|vt+1(st)−v¯t|≤|vt(st)−v¯t|.

（4）TD error 的含义 ​

δt=vt(st)−[rt+1+γvt(st+1)].
  • 它比较相邻两个时刻对同一段回报的估计。下一时刻的估值要先折扣，再加上这一步的奖励。
  • 它反映当前估计 vt 与真实价值 vπ 的差距。把当前估计换成真实价值，记作
δπ,t=˙vπ(st)−[rt+1+γvπ(st+1)].

由贝尔曼期望方程（Bellman expectation equation），

Eπ[δπ,t∣St=st]=vπ(st)−Eπ[Rt+1+γvπ(St+1)∣St=st]=0.
  • 若 vt=vπ，则给定当前价值表和状态，TD error 的条件期望为零。
  • 若这个条件期望非零，则 vt 与 vπ 有差距。即使价值表准确，单次转移仍可能产生非零误差。

2. TD 算法的收敛性、与 MC 的比较 ​

贝尔曼方程与 TD 更新 ​

（1）TD 在求解什么 ​

TD 求解给定策略 π 的贝尔曼方程，得到各状态的价值 vπ。

（2）从回报定义写出状态价值 ​

令 S 为当前状态、R 为下一笔奖励、G 为下一状态起算的后续回报。策略 π 的状态价值为

vπ(s)=E[R+γG∣S=s],s∈S.(4)

（3）用下一状态的价值改写 ​

令 S′ 为下一状态。给定 S′ 后，后续回报的条件期望为 vπ(S′)，所以式（4）可写成

vπ(s)=E[R+γvπ(S′)∣S=s],s∈S.(5)

（4）把贝尔曼方程写成求根问题 ​

对固定状态 s，定义残差函数

g(v(s))=v(s)−E[R+γvπ(S′)∣S=s].

式（5）等价于 g(v(s))=0，可用 Robbins–Monro（RM）算法求根。

（5）把样本残差拆成真残差与噪声 ​

从状态 s 按策略 π 采样一次，得到奖励 r 和下一状态 s′。用它们代替期望，再加减同一个期望项。

g~(v(s))=v(s)−[r+γvπ(s′)]=v(s)−E[R+γvπ(S′)∣S=s]⏟g(v(s))+E[R+γvπ(S′)∣S=s]−[r+γvπ(s′)]⏟η.

噪声 η 是期望目标与样本目标之差。给定 s，其条件期望为零。

（6）写出 RM 更新 ​

vk+1(s)=vk(s)−αkg~(vk(s))=vk(s)−αk(vk(s)−[rk+γvπ(sk′)]),(6)

其中 k=1,2,3,…。vk(s) 是第 k 步对 vπ(s) 的估计，rk,sk′ 是该步对 R,S′ 的采样结果。

（7）式（6）的两个假设 ​

  • 求固定状态 s 的价值时，每一步 k 都要拿到从同一状态 s 出发的经验 (s,rk,sk′)。
  • 任意下一状态 s′ 的真实价值 vπ(s′) 都已知。

（8）改成实际可用的 TD 更新 ​

  • 直接用轨迹上的顺序样本。 将固定 s 的经验改为 {(st,rt+1,st+1)}t，每步更新当下访问的状态 st。
  • Bootstrapping（自举）。 真实价值 vπ(st+1) 未知，用 vt(st+1) 代入式（6），就得到第一节的 TD 更新式（1）。

收敛定理 ​

（9）逐状态的学习率条件 ​

定理 · TD 学习的收敛性

在有限表格型、折扣任务和有界奖励的设定下，固定策略 π。若对每个待估计的状态 s 都有

∑tαt(s)=∞,∑tαt(s)2<∞,

则当 t→∞ 时，式（1）给出的 vt(s) 以概率 1 收敛到 vπ(s)。

说明

  • 收敛目标是给定策略 π 的状态价值。
  • 两个条件要逐状态检查。第 t 步仅对 s=st 取 αt(s)>0，其余状态的步长为零。要让一个状态的步长之和发散，就必须无限次访问该状态。
  • 实践中常用较小的常数学习率。持续访问时，固定正步长的平方和发散。课件指出，在适当条件下，常数步长仍可得到期望意义下的收敛，而上面的概率 1 收敛定理要求平方和有限。

（11）Bootstrapping 与估计方差 ​

TD 状态价值学习 · 算法性质
TD / Sarsa 学习MC 学习
Bootstrapping。 目标用到已有的价值估计，因此需要为价值表设初值。Non-bootstrapping。 用实际回报估计状态或动作价值，目标与价值表初值无关。
方差通常较低。 一步目标用到的随机量较少，例如 Sarsa 使用 Rt+1、St+1 和 At+1。方差通常较高。 估计 qπ(st,at) 要采样完整折扣回报 Rt+1+γRt+2 +γ2Rt+3+⋯。长度为 L 的回合，每步有 |A| 个动作时，单是动作序列就可有 |A|L 种。
TD 与 MC 的比较（续）

在固定策略下，完整 MC 回报的条件期望是真实价值。TD 的目标依赖当前估计，因此早期可能有偏。目标的偏差来自下一状态的估值误差。

3. Sarsa · 动作价值学习 ​

观测五元组 (St,At,Rt+1,St+1,At+1)。固定策略时，下一动作按同一策略抽取：

Yt=Rt+1+γQt(St+1,At+1),Qt+1(St,At)=Qt(St,At)+αt[Yt−Qt(St,At)].

每步只更新当前状态动作对。期望目标来自 qπ 的贝尔曼方程。固定策略评价（policy evaluation）要收敛，需要充分访问各状态动作对，并使用适当步长。用于控制时，按同一个 ε-greedy 策略采样、评价和改进，属于 on-policy 的广义策略迭代（generalized policy iteration，GPI）。固定正探索率时，评价的是仍含探索的策略。

Sarsa · 原课件伪代码 ​

4. Expected Sarsa 与 n-step Sarsa ​

Expected Sarsa 对下一动作求条件期望，环境转移仍用样本。

Yt=Rt+1+γ∑aπt(a∣St+1)Qt(St+1,a).

对给定的下一状态，这一步消除抽取单个动作带来的方差，代价是求和所需的动作值与概率。

n-step Sarsa 用前 n 步真实奖励，再用价值估计补上后续回报。

Gt(n)=∑j=0n−1γjRt+j+1+γnQ(St+n,At+n).

从 t 开始的更新必须等到第 n 步信息就绪，或等回合提前结束。提前结束时只累计到末笔奖励，去掉自举项。n=1 恢复 Sarsa，覆盖整个回合则得到 MC target。增加 n 通常减少对当前估计的依赖，同时纳入更多采样随机性。

5. Q-learning · 最优动作价值学习 ​

用下一状态的最大动作值替换 Sarsa 的下一动作样本：

Yt=Rt+1+γmaxbQt(St+1,b),q∗(s,a)=E[Rt+1+γmaxbq∗(St+1,b)∣s,a].

第一行是一次样本更新的目标，第二行是要解的 Bellman optimality equation。课件第 58 页汇总表的 Q-learning 一栏漏写了折扣因子，按第 43 页及更新式补上 γ。

策略作用
Behavior policy（行为策略）生成经验，可保留探索概率
Target policy（目标策略）决定更新目标。Q-learning 使用当前 Q 的贪心动作

Sarsa 使用行为策略抽出的 At+1 评价同一策略。Q-learning 的最大值与实际执行的下一动作无关，属于 off-policy 更新。课件第 50 页的版本边采样边更新生成经验的策略，Q 更新目标仍取最大值。第 51 页直接使用独立行为策略生成的数据。两种实现都需要充分访问相关状态动作对。

课件的探索实验在比较数据覆盖。均匀探索生成的轨迹能覆盖更多状态动作对。若行为策略长期偏向少数动作，延长轨迹也可能只增加已常见的访问，稀少表项仍难学好。图中的纵轴比较训练中提取的贪心策略价值与已知最优价值的差距。

6. TD 目标汇总 ​

所有动作值更新都可写成 Q←Q+α(Y−Q)，区别集中在目标 Y。

SarsaRt+1+γQ(St+1,At+1)贝尔曼期望方程
Expected SarsaRt+1+γ∑aπ(a∣St+1)Q(St+1,a)贝尔曼期望方程
n-step SarsaGt(n)多步贝尔曼期望方程

MCGt给定策略的完整回报期望
