第 7 课 · 时序差分方法 · V2（总结） ​

1. 时序差分（Temporal-Difference，TD）· State-value Prediction ​

（1）算法描述 ​

TD 状态价值学习 · 算法描述

算法所需的经验

  • 按给定策略 π 生成轨迹（trajectory）(s0,r1,s1,…,st,rt+1,st+1,…)，也可写作经验三元组 {(st,rt+1,st+1)}t。

TD 更新公式

{vt+1(st)=vt(st)−αt(st)[vt(st)−[rt+1+γvt(st+1)]],(1)vt+1(s)=vt(s),∀s≠st,(2)

其中 t=0,1,2,…。vt(st) 是对状态价值（state value）vπ(st) 的当前估计，αt(st) 是状态 st 在第 t 步的学习率（learning rate）。

  • 第 t 步只更新当前访问的状态 st，其他状态按式（2）处理。
  • 下文可省略式（2）。

（2）TD target 与 TD error ​

给更新公式的各项加上标注。

vt+1(st)⏟new estimate=vt(st)⏟current estimate−αt(st)[vt(st)−[rt+1+γvt(st+1)⏟TD target v¯t]⏞TD error δt].(3)

TD target（目标值）

v¯t=˙rt+1+γvt(st+1)

TD error（时序差分误差）

δt=˙vt(st)−[rt+1+γvt(st+1)]=vt(st)−v¯t

新估计等于当前估计减去学习率乘以 TD error。

为什么称为 TD target

每次更新都会把当前状态的估计推向本轮目标。

更新式两边减去 v¯t，再提取公因子。

vt+1(st)=vt(st)−αt(st)[vt(st)−v¯t]vt+1(st)−v¯t=vt(st)−v¯t−αt(st)[vt(st)−v¯t]=[1−αt(st)][vt(st)−v¯t]|vt+1(st)−v¯t|=|1−αt(st)||vt(st)−v¯t|.

当学习率满足 0<αt(st)<1 时，

0<1−αt(st)<1.

于是，新估计与本轮目标的距离缩小。

|vt+1(st)−v¯t|≤|vt(st)−v¯t|.

（3）TD error 的含义 ​

δt=vt(st)−[rt+1+γvt(st+1)].
  • 它比较相邻两个时刻对同一段回报的估计。下一时刻的估值要先折扣，再加上这一步的奖励。
  • 它反映当前估计 vt 与真实价值 vπ 的差距。把当前估计换成真实价值，记作
δπ,t=˙vπ(st)−[rt+1+γvπ(st+1)].

由贝尔曼期望方程（Bellman expectation equation），

Eπ[δπ,t∣St=st]=vπ(st)−Eπ[Rt+1+γvπ(St+1)∣St=st]=0.
  • 若 vt=vπ，则给定当前价值表和状态，TD error 的条件期望为零。
  • 若这个条件期望非零，则 vt 与 vπ 有差距。即使价值表准确，单次转移仍可能产生非零误差。

2. TD 算法的收敛性、与 MC 的比较 ​

（1）Bellman Equation 的期望形式 ​

TD 求解给定策略 π 的贝尔曼方程，得到各状态的价值 vπ。

从回报定义写出状态价值

令 S 为当前状态、R 为下一笔奖励（reward）、G 为下一状态起算的后续回报（return），γ 为折扣因子（discount factor）。策略 π 的状态价值为

vπ(s)=E[R+γG∣S=s],s∈S.(4)

用下一状态的价值改写

令 S′ 为下一状态。给定 S′ 后，后续回报的条件期望为 vπ(S′)，所以式（4）可写成

vπ(s)=E[R+γvπ(S′)∣S=s],s∈S.(5)

（2）用 Robbins–Monro 求解 Bellman Equation ​

写成求根问题

对固定状态 s，定义贝尔曼残差（Bellman residual）

g(v(s))=v(s)−E[R+γvπ(S′)∣S=s].

式（5）等价于 g(v(s))=0，可用 Robbins–Monro（RM）算法求根。

把样本残差拆成真残差与噪声

从状态 s 按策略 π 采样一次，得到奖励 r 和下一状态 s′。用它们代替期望，再加减同一个期望项。

g~(v(s))=v(s)−[r+γvπ(s′)]=v(s)−E[R+γvπ(S′)∣S=s]⏟g(v(s))+E[R+γvπ(S′)∣S=s]−[r+γvπ(s′)]⏟η.

噪声 η 是期望目标与样本目标之差。给定 s，其条件期望为零。

RM 更新

vk+1(s)=vk(s)−αkg~(vk(s))=vk(s)−αk(vk(s)−[rk+γvπ(sk′)]),(6)

其中 k=1,2,3,…。vk(s) 是第 k 步对 vπ(s) 的估计，rk,sk′ 是该步对 R,S′ 的采样结果。

（3）从 RM 更新到 TD 更新 ​

式（6）的两个假设

  • 求固定状态 s 的价值时，每一步 k 都要拿到从同一状态 s 出发的经验 (s,rk,sk′)。
  • 任意下一状态 s′ 的真实价值 vπ(s′) 都已知。

TD 的两处改动

  • 直接用轨迹上的顺序样本。 将固定 s 的经验改为 {(st,rt+1,st+1)}t，每步更新当下访问的状态 st。
  • Bootstrapping（自举）。 真实价值 vπ(st+1) 未知，用 vt(st+1) 代入式（6），就得到第一节的 TD 更新式（1）。

（4）收敛定理与逐状态学习率 ​

定理 · TD 学习的收敛性

在有限状态的表格型（tabular）折扣任务中，固定策略 π，并假设奖励有界。若对每个待估计的状态 s 都有

∑tαt(s)=∞,∑tαt(s)2<∞,

则当 t→∞ 时，式（1）给出的 vt(s) 几乎必然（almost surely，即以概率 1）收敛到 vπ(s)。

说明

  • 收敛目标是给定策略 π 的状态价值。
  • 两个条件要逐状态检查。第 t 步仅对 s=st 取 αt(s)>0，其余状态的步长为零。要让一个状态的步长之和发散，就必须无限次访问该状态。
  • 实践中常用较小的常数步长（constant step size）。持续访问时，固定正步长的平方和发散。课件指出，在适当条件下仍可依期望收敛（convergence in expectation）。上面的几乎必然收敛定理要求平方和有限。

（5）与蒙特卡洛（Monte Carlo，MC）的比较 ​

TD 状态价值学习 · 算法性质

TD 和 MC 都是 model-free（无模型）方法。

更新时机与适用任务

3. Sarsa · Action-value Learning ​

（1）从 State Values 到 Action Values ​

  • 前两节的 TD 算法估计的是 state value vπ(s)。
  • Sarsa 直接估计给定策略 π 的 action value qπ(s,a)，可以比较同一状态下不同动作的价值。这一步是 policy evaluation。
  • 在实际做 control 时，通常把这一步更新与 policy improvement 结合，用更新后的 action value 改进策略。组合后的算法也叫 Sarsa。

（2）Sarsa 更新公式 ​

Sarsa · 算法

给定固定策略 π，用经验 {(st,at,rt+1,st+1,at+1)}t 估计 qπ。下一动作 at+1 从同一策略 π(⋅∣st+1) 采样。

qt+1(st,at)=qt(st,at)−αt(st,at)×[qt(st,at)−[rt+1+γqt(st+1,at+1)]],qt+1(s,a)=qt(s,a),(s,a)≠(st,at).

其中 t=0,1,2,…。

  • qt(st,at) 是 qπ(st,at) 的当前估计。
  • αt(st,at) 是当前 state–action pair 的学习率（learning rate）。

（3）Sarsa 与 TD 的关系 ​

  • 为什么叫 Sarsa？ 每一步用到的五元组依次是 State–Action–Reward–State–Action。
  • 它与 TD 有什么关系？ 把 TD 更新中的状态价值 v(s) 换成动作价值 q(s,a)，并输入实际采样的下一动作，就得到 Sarsa。
  • 它在求解什么？ Sarsa 用随机近似（stochastic approximation）求解动作价值形式的 Bellman expectation equation。
qπ(s,a)=Eπ[R+γqπ(S′,A′)∣S=s,A=a],∀(s,a).

这里 S′ 是下一状态，A′ 按 π(⋅∣S′) 抽取。Sarsa 每次用一次真实转移和下一动作构造期望右侧的样本目标。

（4）Sarsa 的收敛性 ​

定理 · Convergence of Sarsa Learning

沿用上一节的表格型折扣设定，固定策略 π。若对每个待估计的 (s,a) 都满足

∑tαt(s,a)=∞,∑tαt(s,a)2<∞,

则当 t→∞ 时，qt(s,a) 以概率 1 收敛到 qπ(s,a)。未访问的状态动作对当步的学习率为零，因此条件要求每个待估计的状态动作对都被无限次访问。

（5）用 Sarsa 搜索策略 ​

在 Sarsa 的单步价值更新后接一步 policy improvement，就得到用于 control 的 Sarsa。每次交替做一次评价和一次改进，体现了 Generalized Policy Iteration（GPI）。

伪代码 · Policy Searching by Sarsa

对每个 episode，从初始状态 s0 开始，按 π0(⋅∣s0) 采样首个动作 a0。

当前状态 st 尚未到达目标时，重复执行。

执行已选动作 at，观察 rt+1 和 st+1，再按当前策略 πt(⋅∣st+1) 采样 at+1。到达终止状态时，目标只取即时奖励 rt+1，省去下一动作和自举项。

Update q-value（policy evaluation，但只执行一次）

qt+1(st,at)=qt(st,at)−αt(st,at)×[qt(st,at)−[rt+1+γqt(st+1,at+1)]].

Update policy（policy improvement）

在 st 按更新后的 qt+1 选出一个 greedy action a∗，再用 ε-greedy 分配概率。

a∗∈argmaxbqt+1(st,b),πt+1(a∣st)={1−ε|A|(|A|−1),a=a∗,ε|A|,a≠a∗.

若回合继续，进入 st+1 并沿用已采样的 at+1。

使用同一策略采样并评价，属于 on-policy 学习。固定 ε>0 时，执行的是仍含探索的策略。

（6）Gridworld 实验 ​

任务设定

  • 找一条从指定起点到目标状态的好路径。任务只考察这个起点出发的表现，之前的任务要求在每个状态都找到最优策略。
  • 每个 episode 从左上角开始，到达目标状态时结束。

4. Expected Sarsa ​

（1）更新公式：对下一动作取期望 ​

TD 动作价值学习 · Expected Sarsa

Expected Sarsa 是 Sarsa 的一种变体。观察到奖励 rt+1 和下一状态 st+1 后，按当前策略 πt 对下一状态的所有动作加权平均，得到 vt(st+1)。

qt+1(st,at)=qt(st,at)−αt(st,at)×[qt(st,at)−[rt+1+γvt(st+1)]],qt+1(s,a)=qt(s,a),(s,a)≠(st,at).

其中，vt(st+1) 是用当前 action value 估计得到的状态价值：

vt(st+1)=EA∼πt(⋅∣st+1)[qt(st+1,A)]=∑bπt(b∣st+1)qt(st+1,b).

与 Sarsa 相比

  • TD target：Sarsa 使用 rt+1+γqt(st+1,at+1)；Expected Sarsa 使用 rt+1+γvt(st+1)。
  • 计算量与方差：对各动作求和比只查一个动作值更费计算，但消除了由抽取 at+1 带来的目标方差。更新所需的样本从五元组 (st,at,rt+1,st+1,at+1) 减为四元组 (st,at,rt+1,st+1)。

（2）它求解什么：两层期望 ​

给定策略 π，Expected Sarsa 用随机近似求解以下 Bellman expectation equation：

qπ(s,a)=E[Rt+1+γEAt+1∼π(⋅∣St+1)[qπ(St+1,At+1)]⏟vπ(St+1)∣St=s,At=a]=E[Rt+1+γvπ(St+1)∣St=s,At=a],∀(s,a).
  • 内层：对 At+1 求期望。 固定下一状态 St+1，按 π(⋅∣St+1) 对该状态的动作价值加权平均，结果就是 vπ(St+1)。
  • 外层：对 St+1 和 Rt+1 求期望。 给定当前的 (s,a)，对环境可能产生的下一状态和即时奖励取平均；St+1 在内层固定，到外层才作为随机变量参与平均。

实际更新时，内层显式求和，外层用一次环境转移采样。所以 Expected Sarsa 无须知道环境转移概率，奖励和下一状态的随机性仍然存在。

5. n-step Sarsa ​

（1）Action value：从单步形式到 n-step 形式 ​

TD 动作价值学习 · n-step Sarsa

原来的单步形式（Sarsa）：从状态 s 执行动作 a，把下一步奖励与下一状态动作对的折扣价值相加，再取期望。

qπ(s,a)=Eπ[Rt+1+γqπ(St+1,At+1)|St=s,At=a].

新的 n-step 形式（n-step Sarsa）：把奖励展开到前 n 步，再用第 n 步到达的状态动作对的折扣价值补上剩余回报。

qπ(s,a)=Eπ[Gt(n)∣St=s,At=a],Gt(n)=∑j=0n−1γjRt+j+1⏟前 n 步的折扣奖励+γnqπ(St+n,At+n)⏟剩余回报的折扣价值.

两种形式都在计算 qπ(s,a)=Eπ[Gt∣St=s,At=a]，也就是从 (s,a) 出发、此后按策略 π 行动的完整折扣回报的期望。改变的是奖励展开的步数，以及从哪一步开始用价值补尾。 对应的回报形式如下：

SarsaGt(1)=Rt+1+γqπ(St+1,At+1),Gt(2)=Rt+1+γRt+2+γ2qπ(St+2,At+2),n-step SarsaGt(n)=∑j=0n−1γjRt+j+1+γnqπ(St+n,At+n),MCGt(∞)=Rt+1+γRt+2+γ2Rt+3+⋯.

这体现了 truncated policy evaluation 的思路：在第 n 步截断实际采样的回报，再用价值估计补上未展开的尾部。它给出了同一个 action value 的 n-step 表达式。使用真实 qπ 补尾时，替换的是尾部的条件期望，因此各形式对同一起始 (s,a) 的条件期望相同；单条轨迹上的样本回报可以不同。

（2）求解目标与实际更新 ​

三种方法求解的方程（下式中的 ∣s,a 简写 ∣St=s,At=a，期望均在策略 π 下取）：

Sarsa:qπ(s,a)=Eπ[Gt(1)∣s,a]=Eπ[Rt+1+γqπ(St+1,At+1)∣s,a],MC:qπ(s,a)=Eπ[Gt(∞)∣s,a]=Eπ[Rt+1+γRt+2+γ2Rt+3+⋯∣s,a],n-step Sarsa:qπ(s,a)=Eπ[Gt(n)∣s,a]=Eπ[∑j=0n−1γjRt+j+1+γnqπ(St+n,At+n)∣s,a].

从方程到算法。 用采到的奖励替换随机变量，用当前的 q 估计替换尾部的真实 qπ，再把 q(st,at) 朝这个样本目标推一步。在 t 时刻还没有收齐所需经验 (st,at,rt+1,st+1,at+1,…,rt+n,st+n,at+n)，所以要等到 t+n，用更新前的 qt+n−1 来计算：

Yt(n)=∑j=0n−1γjrt+j+1+γnqt+n−1(st+n,at+n),qt+n(st,at)=qt+n−1(st,at)−αt+n−1(st,at)×[qt+n−1(st,at)−Yt(n)].

若回合在第 n 步或之前结束，只累计到最后一笔奖励，去掉 bootstrapping 项。n=1 恢复单步 Sarsa；当 n 覆盖回合剩余的全部步数时，用的就是 MC 的完整回报（课件以 n=∞ 表示这端）。

（3）怎样理解 n 的取舍 ​

  • n 较小，接近 Sarsa：用到的采样奖励少，目标方差通常较低；但更依赖当前 action value 的估计，训练早期更容易受初值的偏差影响。
  • n 较大，接近 MC：用到的采样奖励多，对当前估计的依赖较小，通常减轻由 bootstrapping 引入的偏差，但方差也可能更高。

固定策略时，n-step Sarsa 做的是 policy evaluation；与 policy improvement 结合后，也可以用来寻找最优策略。

6. Q-learning · Optimal Action Values ​

用下一状态的最大动作值替换 Sarsa 的下一动作样本：

Yt=Rt+1+γmaxbQt(St+1,b),q∗(s,a)=E[Rt+1+γmaxbq∗(St+1,b)∣s,a].

第一行是一次样本更新的目标，第二行是要解的 Bellman optimality equation。课件第 58 页汇总表的 Q-learning 一栏漏写了折扣因子，按第 43 页及更新式补上 γ。

策略作用
Behavior policy（行为策略）生成经验，可保留探索概率
Target policy（目标策略）决定更新目标。Q-learning 使用关于当前 Q 的 greedy policy（贪心策略）

Sarsa 使用行为策略抽出的 At+1 评价同一策略。Q-learning 的最大值与实际执行的下一动作无关，属于 off-policy 更新。课件第 50 页的版本边采样边更新生成经验的策略，Q 更新目标仍取最大值。第 51 页直接使用独立行为策略生成的数据。两种实现都需要充分访问相关状态动作对。

课件的实验在比较探索（exploration）如何改变状态动作对的覆盖（coverage）。均匀探索生成的轨迹能覆盖更多状态动作对。若行为策略长期偏向少数动作，延长轨迹也可能只增加已常见的访问，稀少表项仍难学好。图中的纵轴比较训练中提取的 greedy policy 的价值与已知最优价值的差距。
