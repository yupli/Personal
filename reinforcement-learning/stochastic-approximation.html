第 6 课 · Stochastic Approximation and Stochastic Gradient Descent · V2（总结） ​

1. Motivating Example ​

1.1 Mean Estimation ​

Motivating Example · Mean Estimation

第五课用 sample mean 估计期望。给定 N 个 samples，要计算的是

E[X]≈x¯:=1N∑i=1Nxi.

怎样计算 x¯？

  • Batch method。等全部 samples 到齐，再统一求平均。
    • 若 samples 陆续到来，这种做法要等到最后才能给出结果。
  • Incremental method。每收到一个 sample，就更新当前估计。每一步都沿用上一次的结果，因此也是一种 iterative method。

1.2 Incremental Mean Update ​

Incremental Update · 用旧均值和新 Sample 推出新均值

按课件的下标，wk+1 是读入 xk 后的 estimate，包含前 k 个 samples：

wk+1=1k∑i=1kxi,k=1,2,…

相应地，wk 是读入 xk 之前的 estimate：

wk=1k−1∑i=1k−1xi,k≥2.

把旧 samples 的总和写成 (k−1)wk，再加上新 sample xk：

wk+1=1k(∑i=1k−1xi+xk)=1k((k−1)wk+xk).

整理出 update rule：

wk+1=wk−1k(wk−xk).
Incremental Mean · 逐步代入

课件从 w1=x1 开始。将新 sample 依次代入 update rule：

w2=w1−(w1−x1)=x1,w3=w2−12(w2−x2)=12(x1+x2),w4=w3−13(w3−x3)=13(x1+x2+x3).

每一步得到的都是截至当前的 sample mean。读到第 k 个 sample 后，结果为

wk+1=1k∑i=1kxi.

1.3 Remarks ​

Remarks · Estimate 可以随到随用
  • Immediate estimate。新 sample 一到，就能产出新的 mean estimate，可立刻用于后续计算。更新只需要旧 estimate、新 sample 和计数。
  • Early estimates are noisy。前几步 samples 较少，wk 可能离 E[X] 很远，但已经有了可用的阶段性估计。

2. Robbins–Monro Algorithm ​

2.1 Stochastic Approximation ​

Stochastic Approximation (SA)
  • 目标。用随机迭代求解 root finding 或 optimization 问题。
  • 可用信息。以这里的 Robbins–Monro 为例，每轮只用一次带噪声的函数观测来更新。即使 g 的表达式和导数都未知，也可以计算这一步。

2.2 Root Finding with an Unknown Function ​

Problem Statement · 求一个 Root

给定 g:R→R，求满足下式的 w∗：

g(w∗)=0.

例如，对可微的 objective function J(w) 做无约束最小化时，可以先求 stationary point。令 g(w)=J′(w)，问题就变成解 g(w)=0。求到的点还需判断是否是 minimum。

What if g Is a Black Box?

能直接算 g(w) 时，可以用常见的数值求根方法。有些问题只能在指定 w 时得到一条带噪声的信息：

  • Neural network。设总体 loss 为 J(w)=EZ[ℓ(w;Z)]。可以用 backpropagation 算某个 sample 或 minibatch 的 gradient，但数据分布未知时，通常无法直接算出总体 gradient g(w)=∇J(w)。在可交换微分和期望的条件下，可把随机样本的 gradient 当作它的观测。这里用向量参数举例，下面的收敛定理只讨论标量情形。
  • Noisy experiment。想找出使平均读数等于指定 target 的控制量 w。每次调到 w 都能测一个读数，减去 target 就得到一次观测，而读数均值随 w 变化的关系可能未知。

2.3 Robbins–Monro Update ​

Robbins–Monro Update · 用观测修正当前 Estimate
wk+1=wk−akg~(wk,ηk),k=1,2,…
  • wk 是第 k 次 root estimate。
  • g~(wk,ηk)=g(wk)+ηk 是这一步的 noisy observation。
  • ak>0 是 step size。

每轮把 wk 输入 black box，读取 g~(wk,ηk)，再算下一轮的输入 wk+1。

2.4 Illustrative Example · Simulation and Intuition ​

Illustrative Example · tanh
  • Function。g(w)=tanh⁡(w−1)，真实 root 为 w∗=1。
  • Parameters。w1=3，ak=1/k，ηk≡0。

无 noise 时，观测值等于 g(wk)，所以更新简化为

wk+1=wk−1ktanh⁡(wk−1).
Simulation Result · Iterates Approach the Root

横轴的圆点是各步的 estimates w1,w2,…，曲线上的菱形是对应的 g(wk)。这组 iterates 从右侧逐步逼近 w∗=1。

Intuition · 看 g 的符号决定方向

对单调递增的 g，先看无 noise 时的两种情况：

  • 右侧。wk>w∗ 时，g(wk)>0，更新向左移。
  • 左侧。wk<w∗ 时，g(wk)<0，更新向右移。

这解释了更新方向。还要控制 step size，才能避免跨过 root 太远。在上面的 tanh 例子里，|tanh⁡(wk−1)|≤|wk−1| 且 ak≤1，所以每一步都向 root 靠近。

2.5 Robbins–Monro Theorem ​

Theorem · Robbins–Monro Convergence

在标量 Robbins–Monro 更新中，令 Hk 表示已知 wk、尚未收到本轮观测时的历史。下面是一组 sufficient conditions：

  1. Slope bounds。对所有 w，存在常数 0<c1≤g′(w)≤c2<∞。
  2. Step sizes。ak>0，且 ∑k=1∞ak=∞、∑k=1∞ak2<∞。
  3. Noise。E[ηk∣Hk]=0，且条件二阶矩有统一上界 E[ηk2∣Hk]≤M<∞。

在这些条件下，wk almost surely 收敛到唯一的 root w∗。课件把第 3 条简写为条件二阶矩有限，这里写明了统一上界。各条件的作用和 ak=1/k 的计算见附录。证明思路见 Dvoretzky Convergence Theorem。课程教材 §6.2

2.6 When the Conditions Fail ​

When the Conditions Fail · Local Convergence and Constant Step Sizes
  • 初值的影响。g(w)=w3−5 的导数 3w2 缺少全局的正下界和有限上界。初值靠近 root、step size 合适时，迭代仍可收敛。初值离得较远时，更新可能越过 root 很远并发散。
  • Constant step size。不少 RL 算法采用足够小的常数 ak=a>0。这时 ∑kak2 发散。在持续有 noise 时，估计可能在 root 附近波动，这种更新仍可用来跟踪随时间变化的量。

3. Stochastic Gradient Descent (SGD) ​

3.1 Optimization Problem ​

Optimization Problem · Minimize an Expected Loss
minwJ(w),J(w)=EX[f(w,X)].
  • w 是要优化的 parameter。
  • X 是 random variable，期望对 X 的分布取。
  • w 和 X 都可以是 scalar 或 vector，f(w,X) 的输出是 scalar。

下面四种方法都沿负 gradient 的方向更新，差别在于每一步用什么计算 gradient。

3.2 Method 1 · Gradient Descent (GD) ​

Method 1 · Gradient Descent (GD)

在可以交换微分和期望的条件下，GD 每步使用 true gradient：

wk+1=wk−αk∇wJ(wk)=wk−αkEX[∇wf(wk,X)].

αk>0 是 step size。如果 X 的分布未知，或者期望本身难算，这个 gradient 就很难直接得到。

3.3 Method 2 · Batch Gradient Descent (BGD) ​

Method 2 · Batch Gradient Descent (BGD)

用手头全部 n 个 samples 的 gradient 取平均，估计总体 gradient：

EX[∇wf(wk,X)]≈1n∑i=1n∇wf(wk,xi).

于是 update rule 为

wk+1=wk−αk1n∑i=1n∇wf(wk,xi).

右侧的平均值是这批数据的 empirical loss 的精确 gradient。每次 wk 改变后，都要用新的 wk 重新计算整批 samples 的 gradients。

3.4 Method 3 · Stochastic Gradient Descent (SGD) ​

Method 3 · Stochastic Gradient Descent (SGD)

第 k 步只取一个 sample xk，用它的 gradient 直接更新：

wk+1=wk−αk∇wf(wk,xk).
  • Stochastic gradient。∇wf(wk,xk) 是 true gradient 的一次样本估计。若新样本独立于此前的历史且来自 X 的分布，在给定当前 wk 时，它的期望等于 ∇wJ(wk)。
  • 每步只用一个 sample。把每步用于计算平均 gradient 的 sample 数设为 1，就得到这条更新式。每次更新只算一个 gradient，方向也更容易随抽到的 sample 波动。

3.5 Method 4 · Mini-Batch Gradient Descent (MBGD) ​

Method 4 · Mini-Batch Gradient Descent (MBGD)

第 k 步从数据集中取一个 mini-batch，设 batch size 为 m，索引依次为 Ik,1,…,Ik,m。先在同一个 wk 上算这 m 个 samples 的 gradients，再取平均做一次更新：

wk+1=wk−αk1m∑ℓ=1m∇wf(wk,xIk,ℓ).

选择 m 时，要同时考虑每轮的 gradient evaluations 和 gradient noise。不同 batch size 和抽样方式怎样影响这两项，见第 4 节。

3.6 Example and Application ​

Example · Mean Estimation as an Optimization Problem

假设 X 有有限的二阶矩。考虑 squared loss：

J(w)=E[12∥w−X∥2],∇wf(w,X)=w−X.

因此 ∇wJ(w)=w−E[X]，唯一的 minimizer 是 w∗=E[X]。

Application · Recover the Incremental Mean Update

GD 使用 true gradient：

wk+1=wk−αkE[wk−X].

SGD 用本轮 sample xk 计算 stochastic gradient：

wk+1=wk−αk(wk−xk).

取 αk=1/k，就得到第 1 节的 incremental mean estimation。收到第 k 个 sample 后，wk+1 正好等于前 k 个 samples 的平均值。

3.7 Convergence ​

SGD 可以写成求解 ∇wJ(w)=0 的 Robbins–Monro (RM) update。将 stochastic gradient 拆成 true gradient 和 noise 的过程见附录。

Theorem · Convergence of SGD

对于标量 w，假设可以交换微分与期望，并满足以下 sufficient conditions：

  1. Curvature bounds。对所有 w，几乎处处有 0<c1≤∂w2f(w,X)≤c2<∞。
  2. Step sizes。αk>0，且 ∑k=1∞αk=∞、∑k=1∞αk2<∞。
  3. Sampling and noise。每个 xk 独立地从 X 的分布抽取。令 Hk 为抽取前的历史，gradient noise ηk=∂wf(wk,xk)−J′(wk) 满足 E[ηk2∣Hk]≤M<∞，其中 M 与 k 无关。

此时 wk almost surely 收敛到 J′(w∗)=0 的唯一解，也就是 J 的唯一 minimizer。这里写明了与前面 Robbins–Monro Theorem 一致的 noise 条件。课程教材 §6.4

Relative Error · Compare the Two Gradients

记 g(w)=J′(w)。当 g(wk)≠0 时，用 relative error 衡量本轮 gradient noise 相对于 true gradient 的大小：

δk=|∂wf(wk,xk)−g(wk)||g(wk)|=|ηk||g(wk)|.

由 mean value theorem 和 g(w∗)=0，在 wk 与 w∗ 之间存在 w~k，使得

g(wk)=J″(w~k)(wk−w∗).
Curvature Bound · Distance to the Minimizer

若 ∂w2f(w,X)≥c>0，则 J″(w~k)≥c。代入 denominator 得到

|g(wk)|≥c|wk−w∗|,δk≤|ηk|c|wk−w∗|.
Interpretation · Gradient Noise Near the Optimum
  • 离 w∗ 较远时。如果 gradient noise 的幅度相对稳定，较大的 true gradient 会使 relative error 较小，SGD 的更新方向更接近 GD。
  • 靠近 w∗ 时。true gradient 趋近于零。如果 gradient noise 仍有明显波动，relative error 可能增大。实际更新中的 noise 还会乘以 step size αk，因此方向有波动的 iterates 仍可在上述条件下收敛。

距离出现在 relative error 的上界里，δk 本身还取决于每次抽到的 sample。

3.8 A Deterministic Formulation ​

Deterministic Objective · A Fixed Dataset

给定固定的数据 x1,…,xn，可以直接定义 finite-sum objective：

minwJ(w),J(w)=1n∑i=1nf(w,xi).

w 是待优化的 parameter，f(w,xi) 是第 i 条数据对应的 loss。这个 objective 由数据集确定。

Update Rules · Full Gradient or One Component

Full gradient 使用全部 n 项：

wk+1=wk−αk1n∑i=1n∇wf(wk,xi).

如果每步只处理一条数据，就用索引 Ik 选出其中一项：

wk+1=wk−αk∇wf(wk,xIk).

怎样选择 Ik？可以按固定顺序循环，也可以每步随机抽取。后者如何连接到前面的 SGD formulation？

Uniform Index Sampling · Recover the SGD Formulation

令 I 在 {1,…,n} 上均匀分布，并令 X=xI。对每个 i 有 Pr(I=i)=1/n，因此

J(w)=1n∑i=1nf(w,xi)=EI[f(w,xI)].

这是固定数据集上的精确等式。每步独立、均匀地 sampling with replacement，同一个索引可以重复出现。给定抽样前的历史，单样本 gradient 的期望就是 ∇wJ(wk)，满足其余收敛条件时可以应用上面的 SGD theorem。

如果使用固定顺序，就得到 cyclic incremental gradient，其收敛性需要按所用的顺序和 step sizes 分析。

4. BGD, MBGD, and SGD ​

4.1 Update Rules ​

Update Rules · How Many Samples per Step?

给定同一批 n 个 samples，三种方法都使用 wk+1=wk−αkdk。差别在于怎样计算本轮使用的 gradient dk。

BGD · 全部 n 条数据

dk=1n∑i=1n∇wf(wk,xi).

每条数据恰好用一次，得到 exact empirical gradient。在固定 wk 的比较中，来自总体的独立同分布样本足够多时，这个平均值可近似 population gradient。

MBGD · m 次抽样

dk=1m∑ℓ=1m∇wf(wk,xIk,ℓ).

这里每轮从 {1,…,n} 独立、均匀地有放回抽取 m 次。(Ik,1,…,Ik,m) 是索引序列，同一个索引可以出现多次。

SGD · 一次抽样

dk=∇wf(wk,xIk).

每轮随机抽取一个索引，计算一个 stochastic gradient。

4.2 Batch Size and Gradient Noise ​

Batch Size · Gradient Noise and Per-Step Cost
  • 相比 SGD，MBGD 把 m 个独立抽取的 gradients 取平均。给定当前参数和数据集，平均 gradient 的 variance 是单样本 gradient variance 的 1/m（逐分量成立）。
  • 相比 BGD，当 m<n 时，MBGD 每次更新所需的 gradient evaluations 更少。
  • 当 m=1 时，MBGD 就是单样本 SGD。
  • 当 m=n 时，有放回的 MBGD 仍可能重复某些索引、漏掉其他索引。例如 n=3 时，MBGD 可能抽到 (1,1,3)，BGD 每次使用 (1,2,3)。只有每条数据都恰好使用一次，才保证得到同一个 full-batch update。
