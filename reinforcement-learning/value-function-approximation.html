第 8 课 · 价值函数近似 ​

1. Motivating Example · Curve Fitting ​

1.1 从表格到共享参数 ​

Tabular Representation · 每个状态动作对有一格

前七课用表格存储 state value 和 action value。以 qπ 为例，行对应状态，列对应动作，每格存一个 qπ(s,a)。课件中 9 个状态、每个状态 5 个动作，共有 45 个表项。

优点（Advantage）

查表直观，逐项更新也容易分析。

缺点（Disadvantages）

  • Storage。状态或动作越多，需要的表项越多。连续空间无法逐项列成有限表。
  • Generalization。表项各自独立，更新一个表项时，其他表项的估计不会随之改变。
Curve Fitting · 用一条曲线表示多个状态的价值

固定策略 π，把一维状态及其价值看成数据点 (s,vπ(s))。状态很多时，可以用同一个 parameterized function v^(s,w) 来拟合这些点。

1.2 Linear in Parameters ​

Polynomial Features · 直线与二次曲线

直线用 ϕ(s)=[1,s]⊤，二次曲线用 ϕ(s)=[1,s,s2]⊤。两者都可以写成

v^(s,w)=ϕ(s)⊤w.
  • w∈Rm 是 parameter vector，存放要学习的系数。
  • ϕ(s)∈Rm 是状态 s 的 feature vector，存放用来表示该状态的特征。

加入 s2 后，曲线可以弯曲。这里的 linear 指对参数 w 线性，feature 本身可以是状态的非线性函数。

1.3 Quick Summary ​

Value Function Approximation · Storage 与 Generalization

用 v^(s,w)≈vπ(s) 近似状态价值，也可以用 q^(s,a,w) 近似动作价值。

  • Storage。对状态价值而言，参数维数 m 可以远小于状态数 |S|。
  • Generalization。从一个已访问状态得到的经验会更新共享参数 w，也可能改变其他尚未访问状态的价值估计。

Algorithm for state value estimation ​

2. Objective Function ​

2.1 Weighted Value Error ​

Policy Evaluation · 要找怎样的参数？

固定策略 π，用 v^(s,w) 近似真实的 state value vπ(s)。我们要找一组参数 w，让它在整个状态空间上的近似误差尽可能小。这是 policy evaluation，后面再扩展到 policy improvement。

  1. 本节定义 objective function，衡量近似误差。
  2. 下一节从这个目标出发，推导参数更新算法。
Objective · 最小化平方误差

令随机状态 S∼d，寻找使下式最小的 w。

J(w)=12ES∼d[(vπ(S)−v^(S,w))2].

前面的 1/2 方便下一节求导，最优参数与课件中的写法相同。分布 d 决定各状态的误差在目标里占多大权重。

2.2 Uniform Distribution ​

Uniform Distribution · 每个状态权重相同

若有限状态集 S 上的每个状态都取概率 1/|S|，则

J(w)=12|S|∑s∈S(vπ(s)−v^(s,w))2.

缺点。策略 π 对各状态的访问频率可能相差很大，均匀权重会让罕见状态和常见状态同样影响拟合。

2.3 Stationary Distribution ​

Stationary Distribution · 按长期访问频率加权

令 dπ(s) 表示策略 π 诱导的 Markov chain 的 stationary distribution。它满足 dπ(s)≥0，且 ∑s∈Sdπ(s)=1。用它给误差加权，得到

J(w)=12∑s∈Sdπ(s)(vπ(s)−v^(s,w))2.

在遍历条件下，常访问的状态有更大的 dπ(s)，对拟合结果的影响也更大。

Stationary Equation · 一步转移后分布保持不变

记 Pπ(s,s′) 为按 π 从 s 转移到 s′ 的概率。把 dπ⊤ 写成行向量，平稳条件是

dπ⊤=dπ⊤Pπ.

右侧第 s′ 项是 ∑sdπ(s)Pπ(s,s′)，即一步转移后落在 s′ 的总概率。它等于原来的 dπ(s′)，因此状态分布保持不变。

对有限、不可约且非周期的 Markov chain，任意初始分布经过足够多步都会趋近唯一的 dπ。沿一条长轨迹统计各状态的访问比例，也会趋近相应的 dπ(s)。

3. Optimization Algorithms ​

3.1 从 Gradient Descent 到 SGD ​

Gradient Descent · 对目标函数求导

对第 2 节的目标 J(w) 做 gradient descent。

wk+1=wk−αk∇wJ(wk).

令 e(s,w)=vπ(s)−v^(s,w)。固定策略下，vπ 与状态分布 d 都不随 w 变化。对平方误差应用 chain rule，得到

∇wJ(w)=Ed[e(S,w)∇we(S,w)]=−Ed[e(S,w)∇wv^(S,w)].

第 2 节的 1/2 抵消了平方求导产生的 2。

SGD · 用一个状态替代期望

用状态样本 st 计算 stochastic gradient，得到

wt+1=wt+αte(st,wt)∇wv^(st,wt).

这一步仍需要待估计的真实价值 vπ(st)。实际更新可以用下面两种 target 来代替它。

3.2 Monte Carlo 与 TD Learning ​

Monte Carlo · 用完整 Return 作 Target

按 π 生成一个 episode 后，取从 st 开始的 discounted return gt 作为 vπ(st) 的样本。

etMC=gt−v^(st,wt),wt+1=wt+αtetMC∇wv^(st,wt).
TD Update · 用单步 Target 替换未知价值

沿用第七课的 TD target，只需一条转移 (st,rt+1,st+1)。

yt=rt+1+γv^(st+1,wt),δt=yt−v^(st,wt),wt+1=wt+αtδt∇wv^(st,wt).

本次更新把 yt 当作常数，只对当前预测求导，因此叫 semi-gradient。终止转移取 yt=rt+1。

终止转移的 TD target 只取即时奖励。

4. Selection of Function Approximators ​

4.1 Linear 与 Nonlinear Approximators ​

两种 Approximator · 怎样选择模型？
  • Linear function。用 v^(s,w)=ϕ(s)⊤w。Feature vector ϕ(s) 可由 polynomial basis 或 Fourier basis 构成。第 1 节的直线和二次曲线都属于这种形式。
  • Neural network。输入状态 s，输出价值估计 v^(s,w)，网络参数为 w。网络可以表示非线性的价值函数，gradient 可由 backpropagation 计算。

4.2 TD-Linear ​

TD-Linear · Gradient 等于 Feature Vector

对 v^(s,w)=ϕ(s)⊤w 求导，得到 ∇wv^(s,w)=ϕ(s)。代入第 3 节的 semi-gradient TD 更新，得到 TD-Linear。

yt=rt+1+γϕ(st+1)⊤wt,δt=yt−ϕ(st)⊤wt,wt+1=wt+αtδtϕ(st).

终止转移取 yt=rt+1。

Linear Approximation · 优点与缺点

缺点（Disadvantage）

合适的 feature vector 往往难选。训练只能调整已有特征的系数。

优点（Advantages）

  • Linear TD 的收敛性质更容易分析。
  • Tabular representation 是 linear function approximation 的一个特例。

4.3 Tabular TD 是 TD-Linear 的特例 ​

One-hot Features · 每个状态选中一个表项

令 ϕ(s)=es∈R|S|，其中 es 对应状态 s 的分量为 1，其余分量为 0。于是

v^(s,w)=es⊤w=w(s).

代入 TD-Linear 后，普通转移的 TD error 为 δt=rt+1+γwt(st+1)−wt(st)，而向量更新是 wt+1=wt+αtδtest。

两边左乘 est⊤，就只读出状态 st 的分量。

wt+1(st)=wt(st)+αtδt.

只有当前状态的表项被更新，这就是 tabular TD。

4.4 Summary ​

Summary · 从 Policy Evaluation 到 Semi-gradient TD
  1. Objective。固定 π，用 J(w)=12Ed[(vπ(S)−v^(S,w))2] 衡量价值近似的误差。
  2. SGD。对样本 st，用误差 vπ(st)−v^(st,wt) 乘 ∇wv^(st,wt) 来更新参数。
  3. Semi-gradient TD。真实价值未知，用 rt+1+γv^(st+1,wt) 替代 vπ(st)，更新时把这个 target 当作常数。

这三步解释了 TD 更新的来由。换成含当前估计的 TD target 后，更新方向一般会偏离 J(w) 的负梯度。

Theoretical Analysis · 三种误差

令 v^(w) 表示所有状态的价值估计，D=diag(dπ)，∥x∥D2=x⊤Dx。Bellman operator 为 Tπx=rπ+γPπx。

True Value Error 衡量估计与真实价值的差距。在 d=dπ 时，JE(w)=2J(w)。

JE(w)=∥v^(w)−vπ∥D2.

Bellman Error 比较当前估计与一次 Bellman backup 的结果。

JBE(w)=∥v^(w)−Tπv^(w)∥D2.

Projected Bellman Error 先将 backup 的结果投影回线性模型能表示的空间，再比较。ΠD 是按 D 加权的正交投影。

JPBE(w)=∥v^(w)−ΠDTπv^(w)∥D2.

在标准 on-policy 线性收敛条件下，TD-Linear 收敛到 projected Bellman equation 的解，此时 JPBE=0。附录 · Projected Bellman Equation

5. Sarsa with Function Approximation ​

Semi-gradient Sarsa · 从 State Value 换成 Action Value

把第 3 节 semi-gradient TD 的 state value v^(s,w) 换成 action value q^(s,a,w)。下一动作 at+1 按当前策略 πt(⋅∣st+1) 采样。

yt=rt+1+γq^(st+1,at+1,wt),δt=yt−q^(st,at,wt),wt+1=wt+αtδt∇wq^(st,at,wt).

更新时将 yt 当作常数，只对当前预测求导。终止转移取 yt=rt+1。

若未到达终止状态，下一步沿用已采样的动作。终止转移只用即时奖励作 target。

6. Q-learning with Function Approximation ​

Semi-gradient Q-learning · Greedy Target

沿用 Sarsa 的 semi-gradient 更新形式，在下一状态的可用动作中取最大价值。

yt=rt+1+γmaxbq^(st+1,b,wt),δt=yt−q^(st,at,wt),wt+1=wt+αtδt∇wq^(st,at,wt).

终止转移取 yt=rt+1。求 gradient 时把 yt 当作常数。

课件中的 on-policy version 指用当前探索策略在线采样。价值更新使用 greedy target，因此仍属于 off-policy。终止转移只用即时奖励作 target。

7. Deep Q-learning（DQN） ​

7.1 从 Q-learning 到 DQN Loss ​

Deep Q-Network · 用神经网络近似动作价值

DQN 用神经网络作为 nonlinear function approximator 来估计 q∗。沿用第 6 节的 greedy target，把单步 TD error 的平方作为训练信号。先考虑预测和 target 都用同一组参数 w 的写法。

Y(w)=R+γmaxb∈A(S′)q^(S′,b,w),δ(w)=Y(w)−q^(S,A,w),J(w)=E[δ(w)2].

与 Bellman Optimality Equation 的关系。若 q^=q∗，则 E[δ∣S,A]=0。随机奖励或转移仍可能让单次 TD error 非零。这里是先对单次误差平方再取期望，Bellman optimality residual 的平方则是先对误差取条件期望再平方。

因为 w 同时出现在预测和 Y(w) 中，每次更新预测也会改变 target。DQN 用另一组参数计算 target，并把这组参数固定一段时间。

7.2 Online Network 与 Target Network ​

Technique 1 · 固定 Target，再更新 Online Network

Online network（课件也称 main network）用参数 w 预测 q^(S,A,w)。Target network 用参数 wT 计算 YT。

YT=R+γmaxb∈A(S′)q^(S′,b,wT),L(w;wT)=E[(YT−q^(S,A,w))2].

终止转移取 YT=R。固定 wT，记 eT=YT−q^(S,A,w)。平方损失的 gradient 为

∇wL=−2E[eT∇wq^(S,A,w)].

训练时用 mini-batch 的平均值估计这个 gradient，只更新 w。初始化取 wT=w，之后每隔 C 次训练更新执行一次 wT←w。

7.3 Experience Replay ​

Replay Buffer · 随机抽取 Mini-batch

把转移 (s,a,r,s′) 和终止标记存进 replay buffer。每次训练从 buffer 中随机抽一个 mini-batch。这会打散原轨迹的时间顺序，减弱相邻转移的相关性，也允许同一条经验用于多次更新。

均匀抽取的对象是什么？ 目标函数中，(S,A)∼d 决定各状态动作对的权重，给定 (S,A) 后，(R,S′) 的联合分布由环境决定。课件以均匀的 d 说明等权目标。实际的 uniform replay 给 buffer 中每条记录相同的抽样权重，因此状态动作对的权重仍随它在 buffer 中出现的频率变化。

Tabular Q-learning · Replay 也能复用样本
  • 表格法。为每个 (s,a) 求解一条 Bellman optimality equation。采样频率影响更新次数，均匀访问和 replay 都不是必要条件，关键是相关表项得到充分访问。
  • DQN。不同状态动作对共享参数，mini-batch loss 是一个加权平均，采样分布决定拟合更重视哪些数据。
  • 表格法也可以用 replay。一次环境交互产生的转移可以反复用于更新，从而提高 sample efficiency。

Remarks · 课件的三个问题
  1. 为什么没有显式的 policy update？ 这版伪代码用 πb 预先采集经验，训练循环直接更新 Q-network。要执行学到的策略时，按当前 q^ 取 arg⁡maxaq^(s,a,w)，所以更新价值估计也会改变由它导出的 greedy policy。
  2. 为什么这里省略了前面推导的 ε-greedy 更新公式？ 那条公式用新估计调整下一轮采样的行为策略。这里的样本已由 πb 产生，训练时从 buffer 取样。若改为边交互边训练，仍可以用该公式从 online network 构造探索用的 behavior policy，TD target 继续取下一状态的最大动作价值。
  3. 课件和原论文的网络输入输出有什么区别？ 课件输入一对 (s,a)，输出一个 q^(s,a)。Mnih 等人的 DQN 只输入状态表示，一次前向就输出所有离散动作的 Q 值。训练时从输出向量取出实际动作的分量计算损失，计算 target 时对下一状态的输出取最大值。DQN 原论文（Nature, 2015）
Gridworld · 1,000 步与 100 步的覆盖

课件用同一个 5×5 Gridworld 比较两条长度不同的轨迹。1,000 步轨迹覆盖较广，学到的策略更接近最优。100 步轨迹覆盖不足，即使训练 loss 已很低，整体价值估计仍有明显误差。
