V2（总结）

第 8 课 · 价值函数近似 · V2（总结） ​

1. Motivating Example · Curve Fitting ​

1.1 从表格到共享参数 ​

Curve Fitting · 用一条曲线表示多个状态的价值

把每个状态的价值 vπ(s) 看作一个数据点。状态很多时，可以用一个参数化函数 v^(s,w) 拟合这些点。更新共享参数 w，也会改变其他使用这些参数的状态的预测，这就是 generalization。

1.2 Linear in Parameters ​

Polynomial Features · 直线与二次曲线

直线用 ϕ(s)=[1,s]⊤，二次曲线用 ϕ(s)=[1,s,s2]⊤。两者都可以写成

v^(s,w)=ϕ(s)⊤w.

加入 s2 后，曲线可以弯曲。这里的 linear 指对参数 w 线性，feature 本身可以是状态的非线性函数。

2. Objective Function ​

2.1 Weighted Value Error ​

Objective · 哪些状态的误差更重要？

固定策略 π，用状态分布 d 给平方误差加权。系数 1/2 方便求导。

J(w)=12ES∼d[(vπ(S)−v^(S,w))2].
  • Uniform distribution。每个状态权重相同。
  • Stationary distribution。按策略 π 诱导的 Markov chain 的长期访问频率加权，常访问的状态权重更大。

2.2 Stationary Distribution ​

Stationary Distribution · 一步转移后分布保持不变

用行向量记状态分布。若 dπ=dπPπ，则从 dπ 出发做一步转移，状态分布仍是 dπ。有限、不可约且非周期的 Markov chain 会从任意初始分布收敛到这个分布。

因此，按 π 产生的长轨迹可以为这个加权目标提供样本。对于回合任务，长期访问分布还取决于 episode 的重启方式。

在课件的四状态例子里，dπ≈(0.0345,0.1084,0.1330,0.7241)。长轨迹中约 72% 的访问落在第四个状态，所以按 dπ 加权时，第四个状态的误差占更大权重。

3. Optimization · TD with Function Approximation ​

3.1 从 SGD 到 Semi-gradient TD ​

SGD · 理想更新需要真实的 State Value

如果能得到 vπ(st)，第六课的 SGD 给出

et=vπ(st)−v^(st,wt),wt+1=wt+αtet∇wv^(st,wt).
TD Update · 用单步 Target 替换未知价值

沿用第七课的 TD target，只需一条转移 (st,rt+1,st+1)。

yt=rt+1+γv^(st+1,wt),δt=yt−v^(st,wt),wt+1=wt+αtδt∇wv^(st,wt).

本次更新把 yt 当作常数，只对当前预测求导，因此叫 semi-gradient。终止转移取 yt=rt+1。

4. Function Approximators and Gridworld ​

4.1 Linear TD 与 Tabular TD ​

Linear TD · Gradient 就是 Feature Vector

用线性模型时，∇wv^(s,w)=ϕ(s)，所以 wt+1=wt+αtδtϕ(st)。如果 ϕ(s) 是状态的 one-hot vector，每次只改该状态的一个参数，得到第七课的 tabular TD。

也可以用 neural network 直接学习非线性的 v^(s,w)，用 backpropagation 计算 gradient。

4.2 Gridworld · Feature 决定可以拟合的形状 ​

5×5 Gridworld · 用平面拟合价值曲面

以坐标 (x,y) 表示状态，ϕ(s)=[1,x,y]⊤ 只需要三个参数，预测值构成一个平面。课件图中，TD-Linear 学到了价值变化的大致方向，但误差在训练后趋于平稳。

加入 x2,y2,xy 后可拟合二次曲面。课件继续比较了 6 维和 10 维 feature，展示了增加 feature 如何改善这组实验里的拟合。线性 TD 求解的方程见附录。

5. Sarsa and Q-learning with Function Approximation ​

5.1 Sarsa · 用采样到的下一动作 ​

Semi-gradient Sarsa · 从 State Value 换成 Action Value

用 q^(s,a,w) 表示 action value。按当前策略采样 at+1，定义

yt=rt+1+γq^(st+1,at+1,wt).

把误差 δt=yt−q^(st,at,wt) 乘当前预测的 gradient，得到

wt+1=wt+αtδt∇wq^(st,at,wt).

做 control 时，用当前 q^ 构造 ε-greedy policy，继续采样和更新。

5.2 Q-learning · 用下一状态的最大动作值 ​

Semi-gradient Q-learning · Greedy Target

参数更新沿用上一小节的形式。Q-learning 的 target 为

yt=rt+1+γmaxbq^(st+1,b,wt).

两种算法在终止转移都只用即时奖励。Gridworld 实验沿用第七课的指标，用每回合 total reward、episode length 和学到的 greedy policy 检查控制效果。共享参数让一次更新可以影响多个状态动作对。

6. Deep Q-learning ​

6.1 Online Network 与 Target Network ​

DQN Loss · 用暂时固定的 Target 拟合动作价值

DQN 用神经网络近似 q∗。令 w 为 online network 的参数，w− 为 target network 的参数。

y=r+γmaxbq^(s′,b,w−),L(w)=E[(y−q^(s,a,w))2].

终止转移令 y=r。训练时固定 w−，只更新 w，每隔 C 次更新把 w 复制给 w−。这样连续几步使用同一套 target 参数。

6.2 Experience Replay ​

Replay Buffer · 随机抽取 Mini-batch

把每条经验存进 replay buffer，训练时均匀抽取 mini-batch。这样可以复用旧转移，也能减弱连续轨迹中相邻样本的相关性。抽样分布由 buffer 里的数据决定，哪些状态动作对能被学到仍取决于数据覆盖。

6.3 Algorithm and Gridworld Example ​

Pseudocode · Deep Q-learning
  1. 初始化 online network，复制参数到 target network。
  2. 用探索性 behavior policy 收集转移，存入 replay buffer。课件示例使用预先采集的轨迹。
  3. 每次均匀抽取一个 mini-batch，用 target network 计算 y，以平方误差更新 online network。
  4. 每隔 C 次更新同步参数。需要输出策略时，从 online network 取 greedy action。
Gridworld · 1,000 步与 100 步的覆盖

课件用同一个 5×5 Gridworld 比较两条长度不同的轨迹。1,000 步轨迹覆盖较广，学到的策略更接近最优。100 步轨迹覆盖不足，即使训练 loss 已很低，整体价值估计仍有明显误差。
